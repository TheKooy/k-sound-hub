K-Sound Hub icon pack v3

What changed vs v2:
- The "K" is pulled slightly inward and the side audio elements are pushed outward.
- This creates more breathing room left/right, so the logo reads cleaner at launcher size.
- Multiple more colorful gradient variants are included for comparison.

Variants:
- aurora-burst: cyan / lime / violet / pink
- solar-rave: gold / orange / magenta / purple
- prism-pulse: mint / cyan / blue / purple / coral

Files:
- svg/: editable vector sources
- png/: rendered exports in 1024, 512, 256, 128, 64
- rounded = app/launcher icon
- transparent = overlay / branding / compositing use
